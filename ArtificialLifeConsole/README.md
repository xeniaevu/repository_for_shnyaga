# «Искусственная жизнь» — консольная версия (предварительная)

Отдельный проект с консольным вариантом программы. Модель (`src/lifesim/model`) —
та же, что в оконной версии, скопирована без изменений.

## Структура

```
src/lifesim/
  model/  — модель: среда, агенты, энергия, логика (как в оконной версии)
  view/ConsoleView.java  — вывод поля символами P / T / X
  app/ConsoleMain.java   — точка входа: цикл «команда → шаги → вывод поля»
```

## Запуск

**IntelliJ IDEA:** File → Open → папка `ArtificialLifeConsole`, затем запустить конфигурацию
`ConsoleMain` (зелёная кнопка ▶). Ввод команд — в окне Run внизу.

**Терминал (JDK 17+):**
```
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out lifesim.app.ConsoleMain
```

## Управление

- Enter — один шаг;
- число N — сделать N шагов и показать поле;
- q — выход.

Обозначения: `P` — растение, `T` — травоядное, `X` — хищник, `.` — пустая клетка.
Под полем печатаются номер шага и численность каждого вида.
Если один из видов вымирает, программа сообщает об этом и завершается.

Параметры — те же, что в оконной версии (`new SimulationConfig()`): поле 100×60,
в начале 1680 растений, 360 травоядных, 72 хищника. Поле занимает 102 символа в ширину,
поэтому окно Run в IntelliJ (или терминала) должно быть достаточно широким.

Почему не `SimulationConfig.consoleDefaults()` (поле 80×40): проверка показала, что на таком
поле жизнь сохраняется до 10 000 шагов лишь примерно в трети прогонов — популяции малы и
вымирают случайно. На поле 100×60 жизнь сохранилась во всех 16 прогонах по 10 000 шагов.
