# Мир вампуса — логический агент на Java (Swing)

Реализация задачи из главы 7 «Логические агенты» (Рассел, Норвиг): среда «Мир вампуса»
и агент, основанный на знаниях, который исследует пещеру, делает логические выводы,
рискует, когда безопасных ходов нет, и стреляет в вампуса.

## Запуск

Нужна Java 17 или новее.

- **Готовый файл:** `java -jar wumpus.jar` (или двойной щелчок по `wumpus.jar`).
- **IntelliJ IDEA:** File → Open → папка проекта (подхватится `pom.xml`), запустить `wumpus.Main`.
- **Из консоли без Maven:**
  ```
  javac -d out $(find src -name "*.java")
  java -cp out wumpus.Main
  ```
  В Windows вместо `$(find ...)`: `dir /s /b src\*.java > files.txt` и `javac -d out @files.txt`.
- **Массовый прогон без интерфейса:**
  `java -cp wumpus.jar wumpus.Benchmark [игр] [ширина] [высота] [p_ямы] [допустимый_риск]`

## Правила (как договорились)

| | |
|---|---|
| Поле | от 2×2 до 15×15, ширина и высота задаются отдельно; старт в [1,1], лицом на восток |
| Генерация | вампус и золото — в случайных клетках, кроме [1,1]; в каждой другой клетке яма с вероятностью p (по умолчанию 0,2) |
| Очки | −1 за **любое** действие (шаг, поворот, Grab, Shoot, Climb); −10 дополнительно за выстрел; −1000 за смерть; +1000 за `Climb` в [1,1] **с золотом** |
| Конец игры | агент погиб или выбрался (`Climb`). Победа — выбрался с золотом |
| Восприятия | `[Stench, Breeze, Glitter, Bump, Scream]`, как в книге |

## Как устроен агент

**База знаний** (`KnowledgeBase`) хранит только то, что агент почувствовал, и правила игры.
Вывод — **проверка по моделям** из раздела 7.3:

- **Ямы.** Неизвестные клетки рядом с посещёнными образуют «границу». Перебираются все
  расстановки ям на границе, совместимые с наблюдениями (ветерок ⇔ рядом яма). Если во
  всех таких моделях в клетке нет ямы — это **OK**, если яма есть во всех — **P!**. Иначе доля
  моделей с ямой (с весом p^ям·(1−p)^пустых) — это вероятность ямы **P?**.
  Граница делится на независимые компоненты, поэтому перебор остаётся маленьким даже на
  большом поле. Компоненты до 18 клеток перебираются точно; больше (бывает только на
  огромных полях) — вероятности оцениваются выборкой, а достоверные выводы остаются точными.
- **Вампус.** Он ровно один, поэтому модель — это его клетка. Перебираются все клетки,
  остаются согласованные с запахами и выстрелами; если осталась одна — **W!**.

**Решения на каждом шаге** (`Agent`):

1. Блеск → `Grab`; с золотом → кратчайший путь в [1,1] и `Climb`.
2. Есть достижимая клетка OK → идти в ближайшую (путь учитывает повороты, они тоже стоят −1).
3. Безопасных ходов нет → для каждой граничной клетки считается риск гибели. Если там может
   быть вампус и стрела окупается (вероятность вампуса × 1000 > 10), агент сначала стреляет:
   после выстрела вампуса там точно нет (либо убит, либо стрела прошла мимо).
4. Если наименьший риск ≤ «Допустимый риск» — агент рискует, иначе возвращается без золота.

Пример из книги (кнопка «Мир из книги») агент проходит так же, как в тексте: в [1,2] выводит
OK для [2,2], яму в [3,1] и вампуса в [1,3], находит золото в [2,3] и выходит со счётом 978.

## Результаты (10 000 случайных пещер 4×4, p = 0,2)

| Допустимый риск | Победы | Погиб | Ушёл без золота | Средний счёт |
|---|---|---|---|---|
| 0 (никогда не рискует) | 35,2% | 0% | 64,8% | 338 |
| **0,30 (по умолчанию)** | **38,0%** | 2,3% | 59,8% | **343** |
| 0,50 | 44,6% | 10,7% | 44,7% | 323 |

Золото вообще достижимо (не в яме и не отрезано ямами) только в 74% пещер. При стартовом
ветерке в [1,1] риск первого шага около 56%, поэтому агент часто уходит сразу. Порог 0,30 даёт
лучший средний счёт, а более высокий порог приносит больше побед ценой большего числа смертей.

## Интерфейс

- Сверху: размер поля, вероятность ямы, допустимый риск (меняется прямо во время игры),
  seed (пусто — случайная пещера, число — одна и та же пещера).
- Кнопки: «Шаг» (или пробел), «Авто», «До конца», «Заново ту же», «Мир из книги».
- Поле показывает знания агента: V, OK, B, S, G, P!, W!, P?/W? с процентами; чем краснее
  клетка, тем опаснее. «Показать настоящую карту» открывает ямы, вампуса и золото.
  После конца игры карта открывается сама.
- Справа — журнал рассуждений: что агент почувствовал, что вывел и почему выбрал ход.

## Структура

```
src/main/java/wumpus/
  Main.java              точка входа (GUI)
  Game.java              игровой цикл: действие → восприятие
  Benchmark.java         массовый прогон без интерфейса
  world/                 среда: Grid, Position, Direction, Action, Percept, World
  agent/                 KnowledgeBase (вывод), PathFinder (путь с поворотами), Agent (решения)
  gui/                   WumpusFrame (окно), BoardPanel (рисование поля)
```
