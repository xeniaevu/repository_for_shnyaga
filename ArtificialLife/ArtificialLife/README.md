# Лабораторная работа №1 «Искусственная жизнь» (Java)

## Структура проекта

```
src/lifesim/
  model/       — модель (среда, агенты, энергия, логика)
    Agent.java             абстрактный агент: координаты, энергия, жизненный цикл live()
    Animal.java            абстрактное животное: зрение 5×5, движение, поедание
    Plant.java             растение: рост +n за шаг, вегетативное размножение
    Herbivore.java         травоядное: убегает / ест / идёт к растению / блуждает
    Predator.java          хищник: (если голоден) атакует / преследует / блуждает
    Environment.java       сетка W×H: getAgent, setAgent, getNeighbors(x, y, radius)
    Simulation.java        один виток времени step(), статистика, история
    SimulationConfig.java  все параметры модели
    PopulationStats.java, Position.java, Direction.java
  controller/
    SimulationController.java  игровой цикл (javax.swing.Timer): старт/пауза/шаг/сброс
  view/
    MainFrame.java     главное окно (размер, значок, заголовок на macOS)
    MainPanel.java     содержимое окна: панель управления, поле, строка состояния
    GridPanel.java     отрисовка поля
    SettingsDialog.java  окно параметров модели
    Theme.java, FlatButton.java, SpeedSlider.java — оформление (цвета, шрифты, кнопки, ползунок)
    ConsoleView.java — вывод в консоль символами P / T / X
  app/
    GuiMain.java      — оконная версия (окончательная)
    ConsoleMain.java  — консольная версия (предварительная)
    BalanceTest.java  — прогоны без графики для проверки баланса
uml/           — PlantUML-исходники всех диаграмм для отчёта
```

## Запуск

**IntelliJ IDEA:** File → Open → папка проекта, пометить `src` как Sources Root
(ПКМ → Mark Directory as → Sources Root), затем запустить `GuiMain` или `ConsoleMain`.

**Командная строка (JDK 17+):**
```
javac -encoding UTF-8 -d out src/lifesim/model/*.java src/lifesim/controller/*.java src/lifesim/view/*.java src/lifesim/app/*.java
java -cp out lifesim.app.GuiMain          # оконная версия
java -cp out lifesim.app.ConsoleMain      # консольная версия
java -cp out lifesim.app.BalanceTest 10 5000   # 10 прогонов по 5000 шагов
```
Если в консоли Windows кириллица выводится «кракозябрами», выполните `chcp 65001`.

**macOS:** нужен JDK 17 или новее (например, `brew install openjdk`); команды те же.
Если IntelliJ сообщает, что SDK не найден: File → Project Structure → SDK → выбрать установленный JDK.

Консоль: Enter — один шаг, число N — N шагов, q — выход.
Окно: Старт/Пауза, Шаг, Сброс, «Параметры» (все коэффициенты), ползунок скорости;
внизу — численность каждого вида и номер шага. При наведении мыши на клетку внизу видны
вид, энергия и возраст агента, а у животного подсвечивается область видимости 5×5.
Клавиши: пробел — старт/пауза, → — шаг, ⌘R / Ctrl+R — сброс, ⌘, / Ctrl+, — параметры.

## Правила модели

- Поле — двумерный массив, в клетке не больше одного агента.
- Ходы только по вертикали/горизонтали на 1 клетку, по диагонали нельзя.
- Поедание возможно, только если жертва в соседней клетке по стороне (не по диагонали);
  съевший в этот же ход встаёт на клетку жертвы (как взятие в шахматах).
- Зрение животных — квадрат 5×5 с агентом в центре.
- На каждом шаге агенты ходят в случайном порядке.
- Энергия: животные тратят F (F2) за шаг, растения получают +n. E ≤ 0 → смерть.
  E > порога → в свободной соседней клетке появляется потомок с E_child, у родителя E −= E_child.

**Травоядное**
```
ЕСЛИ видит хищника              ТО убегает (только по свободным клеткам, не ест)
ИНАЧЕ ЕСЛИ растение по соседству ТО съедает его и встаёт на его клетку
ИНАЧЕ ЕСЛИ видит растение        ТО шаг к ближайшему
ИНАЧЕ                            случайный шаг
```
Бегство: из свободных соседних клеток (и варианта «остаться») выбирается клетка с
максимальным манхэттенским расстоянием до ближайшего хищника, при равенстве — с максимальной
суммой расстояний до всех видимых хищников, при полном равенстве — случайная. Манхэттенское
расстояние выбрано потому, что хищник ходит и атакует только по прямым: отход назад по линии
и отход вбок увеличивают дистанцию одинаково.

**Хищник**
```
ЕСЛИ голоден И травоядное по соседству ТО съедает его и встаёт на его клетку
ИНАЧЕ ЕСЛИ голоден И видит травоядное  ТО шаг к ближайшему
ИНАЧЕ                                   случайный шаг
```
«Голоден» — энергия ниже порога сытости. Без этого условия хищники истребляли травоядных
и вымирали от голода.

**Растение** — не двигается, E = min(E + n, E_max), размножается в соседние клетки.
Дополнительно с малой вероятностью в пустой клетке прорастает «семя, занесённое ветром».

## Итоговые параметры (подобраны эмпирически)

| Параметр | Значение |
|---|---|
| Поле M×N (окно / консоль) | 100×60 / 80×40 |
| Начальное число P / T / X (окно) | 1680 / 360 / 72 |
| Растения: +n за шаг, E_max, P_threshold, E_child | 1, 20, 10, 5 |
| Семена ветром (вероятность на пустую клетку за шаг) | 0.0005 |
| Травоядные: начальная E, F, E1 (от растения), H_threshold, E_child | 20, 1, 6, 50, 23 |
| Хищники: начальная E, F2, E2 (от травоядного), порог сытости, X_threshold, E_child | 60, 1, 40, 180, 200, 60 |

Результаты проверки (BalanceTest):
- поле 100×60 — жизнь сохранилась в 8 из 8 прогонов по 20 000 шагов;
- поле 80×50 — в 14 из 16 прогонов по 20 000 шагов;
- поле 80×40 — в 8 из 10 прогонов по 10 000 шагов;
- на полях меньше ~60×30 популяции слишком малы и случайно вымирают.

Численность колеблется по классической схеме «хищник — жертва»: рост растений → рост
травоядных → рост хищников → спад травоядных → спад хищников → восстановление растений.

## UML-диаграммы

Файлы в папке `uml/` — исходники PlantUML:
1_usecase (прецедентов), 2a–2d_activity (деятельности: шаг модели, травоядное, хищник,
растение), 3_class (классов), 4_sequence (последовательности/взаимодействия),
5_component (компонентов).

Получить картинки: вставить текст файла на https://www.plantuml.com/plantuml
или установить плагин PlantUML Integration в IntelliJ IDEA и экспортировать в PNG.
