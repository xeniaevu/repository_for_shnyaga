# Муравьиный алгоритм (Ant System) — задача коммивояжёра

Программа на Java с визуализацией: муравьи ищут кратчайший замкнутый маршрут через все узлы графа.
Сторонние библиотеки не нужны — только JDK 8 или новее (графика на Swing).

## Запуск

- **Готовый файл:** `java -jar AntColony.jar` (или двойной щелчок по `AntColony.jar`).
- **Из исходников:** `run.bat` (Windows) или `./run.sh` (macOS / Linux) — скрипт компилирует и запускает.
- **IntelliJ IDEA / Eclipse:** открыть папку проекта, пометить `src` как папку исходников, запустить `antcolony.Main`.
- **Проверка без графики:** `java -cp out antcolony.ConsoleDemo` — пример «два муравья» из методички
  и прогон на случайном графе со сравнением с точным решением.

## Что видно на экране

- Оранжевые линии — феромон: чем толще и ярче линия, тем больше феромона на пути.
- Зелёный пунктир на графе — лучший маршрут, найденный муравьями (не точный оптимум).
- Фиолетовый пунктир на графике — точный оптимум (только для графов до 15 узлов).
- В начале феромон одинаков на всех путях, и муравьи ходят по всем дорогам случайно.
  Через несколько десятков циклов феромон остаётся только на одном маршруте, и все муравьи идут по нему.
- Внизу график: длина лучшего и среднего маршрута в каждом цикле и точный оптимум.
- Справа статистика, в том числе «Муравьёв на лучшем маршруте: N из M» и «Точный оптимум»
  (считается перебором Хелда — Карпа для графов до 15 узлов — так можно убедиться, что найденный путь кратчайший).
- Узлы можно перетаскивать мышью прямо во время работы: среда меняется, колония перестраивается.

Кнопки: «Старт / Пауза», «Один цикл», «Сброс феромона», «Новый граф».
Расположение «По окружности» удобно для демонстрации: кратчайший маршрут очевиден — обход по контуру.

## Алгоритм

1. Муравьи равномерно распределены по узлам, на всех путях одинаковый феромон.
2. Муравей в узле r выбирает следующий непосещённый узел u с вероятностью
   `P = tau(r,u)^alpha * eta(r,u)^beta / сумма по непосещённым`, где `eta = 1 / d(r,u)`.
3. Обойдя все узлы и вернувшись в начало, муравей получает длину маршрута `L`
   и откладывает на каждом пути маршрута `delta tau = Q / L`.
4. После того как все муравьи закончили цикл: `tau = tau + rho * сумма(delta tau)`,
   затем испарение `tau = tau * (1 - rho)`.
5. Цикл повторяется.

Формулы обновления взяты по числовому примеру из методички (rho = 0.6, Q = 10):
`0.1 + 0.5 * 0.6 = 0.4`, после испарения `0.4 * (1 - 0.6) = 0.16`. `ConsoleDemo` воспроизводит эти числа.

**«Элитные муравьи»** (флажок, включён по умолчанию) — известное расширение Ant System: лучший найденный
маршрут в каждом цикле подкрепляется дополнительно. Без него классический алгоритм находит короткий маршрут,
но часть муравьёв продолжает блуждать; с ним все муравьи сходятся на один маршрут. Флажок можно снять,
чтобы посмотреть классический вариант.

## Структура

```
src/antcolony/
  Main.java              точка входа (окно с визуализацией)
  ConsoleDemo.java       проверка в консоли
  model/
    Node.java            узел сети (город)
    Path.java            путь (ребро): длина, феромон, обновление, испарение
    Graph.java           полный граф: узлы и пути
  algorithm/
    Ant.java             муравей: выбор следующего пути, перемещение, откладывание феромона
    AntColony.java       колония: циклы алгоритма, обновление феромона, лучший маршрут
    Parameters.java      параметры alpha, beta, rho, Q и др.
    ExactSolver.java     точное решение для проверки
  ui/
    MainFrame.java       главное окно
    SimulationView.java  таймер анимации, связь модели и интерфейса
    GraphPanel.java      рисование графа, феромона и муравьёв
    ChartPanel.java      график сходимости
    ControlPanel.java    кнопки, параметры, статистика
```
